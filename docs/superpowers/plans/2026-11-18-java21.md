# Java 21 Compatibility Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build, test, and run InterMine on Java 21 while retaining Java 8-compatible artifacts during the transition.

**Architecture:** Keep Gradle 8.14.7 and Tomcat 9. Diagnose failures on Java 21, update the dependencies or code responsible, and retain Java 8 as a compatibility check. Do not use blanket module-opening flags to conceal incompatible runtime dependencies.

**Tech Stack:** Java 21/8, Gradle 8.14.7, PostgreSQL 14, Tomcat 9, Solr 8.

**Spec:** The accepted migration described in the conversation: Java 21 first, compatible artifacts initially, and a separate servlet/framework migration later.

## Global Constraints

- Preserve application behavior, generated model semantics, and published artifact names.
- Keep source and target compatibility at Java 8 for this migration.
- Limit dependency changes to those needed for compatibility.
- Run Aislop and fix blocking findings without changing its configuration.

## Review Focus

- Dynamic model objects: proxies, inheritance, equality, serialization, and lazy references.
- Generated source and bytecode: Java 8 runtime compatibility after compilation on Java 21.
- XML providers and JAXB: complete compile and deployment classpaths.
- Database integration and importer tests: clean generated resources and real PostgreSQL execution.
- Deployed web services: Tomcat startup, queries, authentication, and Solr-backed search.
